## Tips

- Capture at **1440 × 900** or wider so the sidebar and content both fit.
- Leave **Show scores & maths** *on* — the numbers are the point of the project.
- A couple of shots in **dark** theme and the rest in light reads well; the theme swatches are in
  the sidebar footer.
- On Windows: `Win + Shift + S` for a region grab, or `Win + PrtScn` for the full screen.
- Keep them under ~500 KB each so the repo stays light — PNG is fine, or export JPEG at ~85%.

If you would rather not add screenshots, delete the `![...](docs/screenshots/...)` lines from
`README.md`; everything else in it stands on its own.
